Each importer needs its own reader

Factory Method

New ticket

Let us preview a file before importing it, and accept Excel files

From Mona Saleh, Head of Quality

Last week we imported a file into the wrong term because nobody looked at it first. Please show the first rows before importing. Also, schools using Excel on Arabic Windows send "CSV" files separated by semicolons, which start with strange characters (﻿).

Why the quick fix is a trap

The preview needs to read the files too. The quick fix writes a second reader:

the quick fix (we won’t do this)
public function preview(string $path, string $format): array
{
    if ($format === 'google') {
        // a copy of GoogleFormsCsvImport::readRows()
    } elseif ($format === 'microsoft') {
        // a copy of MicrosoftFormsJsonImport::readRows()
    } elseif ($format === 'excel') {
        // a third CSV reader, with ';'
    }
}

Every format’s reading code now exists twice, and each new format needs an edit in two places. Worse, the two CSV readers already differ in how they handle Excel’s byte-order mark.

Reading a file is a job of its own. It should live in reader objects, and each importer should only say which reader it needs.

The pattern: Factory Method

Remember itA base class needs an object but shouldn’t decide which class it is → it calls an abstract "create" method, and each subclass returns the object it needs.

Reading moves into small RowReader classes: CsvRowReader (any delimiter, strips Excel’s byte-order mark) and JsonRowReader. They can be used anywhere.

AnswerImport gets an abstract method createReader(): RowReader. This is the factory method. Both import() and the new preview() call it; neither knows which reader they get. Each subclass answers with one line: return new CsvRowReader(';');.

Compare it with Simple Factory (chapter 4): there, one class decides with a match. Here, the decision is spread over subclasses, through inheritance. The Excel format is a new subclass; nothing existing changes.

/**

 */
interface RowReader
{
    /** @return iterable<int, array<string, string>> row number (or id) => column name => value */
    public function rows(string $path): iterable;
}

  2. 2One CSV reader for every delimiter

    The code that used to live inside GoogleFormsCsvImport, now reusable. It also skips the three-byte UTF-8 byte-order mark (the "﻿" Mona saw) that Excel writes at the start of the file.

    src/Import/CsvRowReader.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Evalu8\Import;

use RuntimeException;

/**
 * Reads a CSV file whose first line holds the column names.
 * Handles any delimiter, and the byte-order mark Excel adds to UTF-8 files.
 */
final readonly class CsvRowReader implements RowReader
{
    private const UTF8_BOM = "\xEF\xBB\xBF";

    public function __construct(private string $delimiter = ',')
    {
    }

    public function rows(string $path): iterable
    {
        $file = fopen($path, 'r');
        if ($file === false) {
            throw new RuntimeException("Can't open {$path}.");
        }

        try {
            if (fread($file, 3) !== self::UTF8_BOM) {
                rewind($file);                              // no BOM: start again from the first byte
            }

            $header = fgetcsv($file, separator: $this->delimiter, escape: '');
            if ($header === false) {
                return;
            }

            $line = 1;
            while (($values = fgetcsv($file, separator: $this->delimiter, escape: '')) !== false) {
                $line++;
                if ($values === [null]) {
                    continue;                               // a blank line
                }

                /** @var array<string, string> $row */
                $row = array_combine($header, array_pad(array_map('strval', $values), count($header), ''));
                yield $line => $row;
            }
        } finally {
            fclose($file);
        }
    }
}

    src/Import/JsonRowReader.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Evalu8\Import;

use RuntimeException;

/**
 * Reads a JSON list of submissions, e.g. [{"id": 1, "answers": {...}}, ...].
 */
final readonly class JsonRowReader implements RowReader
{
    public function __construct(
        private string $idField = 'id',
        private string $rowField = 'answers',
    ) {
    }

    public function rows(string $path): iterable
    {
        $json = file_get_contents($path);
        if ($json === false) {
            throw new RuntimeException("Can't open {$path}.");
        }

        /** @var list<array<string, mixed>> $items */
        $items = json_decode($json, true, flags: JSON_THROW_ON_ERROR);

        foreach ($items as $item) {
            /** @var array<string, string> $row */
            $row = $item[$this->rowField] ?? [];
            yield (int) ($item[$this->idField] ?? 0) => $row;
        }
    }
}

  7. 7The new format: one small subclass

    A semicolon reader and its own column names. That is the whole format.

    src/Import/ExcelCsvImport.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Evalu8\Import;

/**
 * Evalu8's Excel template, saved as "CSV UTF-8". Excel in Arabic and many European locales
 * separates columns with ";" and starts the file with a byte-order mark.
 */
final class ExcelCsvImport extends AnswerImport
{
    protected function createReader(): RowReader
    {
        return new CsvRowReader(';');
    }

    protected function mapRow(array $row): RawAnswer
    {
        return new RawAnswer($row['Teacher'], $row['Role'], $row['Score'], $row['Comment']);
    }

    protected function sourceName(): string
    {
        return 'Excel CSV';
    }
}

How Laravel does it

Laravel’s Manager classes (chapter 8) use factory methods: SessionManager has createFileDriver(), createDatabaseDriver(), createRedisDriver(), and the base class calls the right one by name.

In tests, Eloquent model factories follow the same idea: UserFactory::definition() is a method each factory overrides to say what to create.

Laravel
final class TeacherFactory extends Factory
{
    // The base Factory class calls this to know what to build.
    public function definition(): array
    {
        return ['name' => fake()->name(), 'email' => fake()->safeEmail(), 'school' => 'Smouha'];
    }
}

Check yourself

Answer in your head, then open the answer.

How is Factory Method different from Simple Factory?

A Simple Factory is one class that decides with a match. A Factory Method is an abstract method in a base class; each subclass decides by overriding it.

Why can preview() support every format without an if?

It calls createReader(), and each subclass already returns the right reader.

The Google CSV starts using semicolons. What changes?

One line in GoogleFormsCsvImport::createReader(): new CsvRowReader(';').
