Adapter

StructureGoF book

A travel plug: your charger, their wall socket.

The rule to rememberA third-party class has the wrong shape and you can't edit it → wrap it in a class that speaks YOUR interface.

Without it: the pain

The SMS provider SDK is called directly in 12 places. Switching provider means editing 12 files.

With it: the fix

Your app only knows SmsSender. One adapter class talks to the SDK. Switching = one new adapter.

Reach for it when you see

  • A vendor SDK is called directly all over your code
  • "We might switch provider" is said in a meeting
  • The SDK returns false / status arrays instead of throwing

Real job where it fits

You send SMS through Twilio today. Management wants to try Vonage next quarter.

Before: the code that hurts

// in 12 different controllers and jobs:
$twilio = new \Twilio\Rest\Client(config('services.twilio.sid'), config('services.twilio.token'));
$twilio->messages->create($phone, ['from' => '+1555...', 'body' => $text]);

After: how you implement the Adapter pattern in PHP

interface SmsSender                                  // YOUR shape
{
    public function send(string $to, string $text): void;
}

final class TwilioSmsSender implements SmsSender  // the adapter
{
    public function __construct(
        private \Twilio\Rest\Client $twilio,
        private string $from,
    ) {}

    public function send(string $to, string $text): void
    {
        $message = $this->twilio->messages->create($to, [  // translate the call
            'from' => $this->from,
            'body' => $text,
        ]);

        if ($message->status === 'failed') {  // translate failure into an exception
            throw new SmsFailed("SMS to {$to} failed: {$message->errorMessage}");
        }
    }
}

// AppServiceProvider: switching provider later = change this one binding
$this->app->bind(SmsSender::class, fn () => new TwilioSmsSender(
    new \Twilio\Rest\Client(config('services.twilio.sid'), config('services.twilio.token')),
    config('services.twilio.from'),
));

// Everywhere else:
public function __construct(private SmsSender $sms) {}
$this->sms->send($user->phone, 'Your report is ready.');
