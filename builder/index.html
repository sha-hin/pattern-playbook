Builder

CreationGoF book

Ordering at Subway: bread, then fillings, then sauce; the cashier checks it at the end.

The rule to rememberAn object with many optional parts and rules that involve several parts → set parts step by step, check everything once in build().

Without it: the pain

A constructor with 7 arguments, half of them null. Nobody knows what the 4th one is.

With it: the fix

Named steps in any order. build() checks the rules that need several fields, then creates a locked object.

Reach for it when you see

  • Constructor with 5+ parameters, many nullable
  • Rules like "if A is set, B must be…"
  • The object is filled in over several screens or steps

Real job where it fits

A search API with optional filters: school, subjects, date range, page size. "from" must be before "to".

Before: the code that hurts

$search = new EvaluationSearch(12, null, null, ['math'], null, 25, true);
// which argument is "from"? which is "to"? is from < to? nobody checks

After: how you implement the Builder pattern in PHP

final class EvaluationSearchBuilder
{
    private ?int $schoolId = null;
    private array $subjects = [];
    private ?string $from = null;
    private ?string $to = null;
    private int $perPage = 25;

    public function school(int $id): self              { $this->schoolId = $id; return $this; }
    public function subjects(string ...$s): self       { $this->subjects = $s; return $this; }
    public function between(string $from, string $to): self { $this->from = $from; $this->to = $to; return $this; }
    public function perPage(int $n): self              { $this->perPage = $n; return $this; }

    public function build(): EvaluationSearch  // every rule checked here, once
    {
        if ($this->from !== null && $this->from > $this->to) {
            throw new InvalidArgumentException('"from" must be before "to".');
        }
        if ($this->perPage < 1 || $this->perPage > 100) {
            throw new InvalidArgumentException('perPage must be between 1 and 100.');
        }

        return new EvaluationSearch(                    // readonly: can't become invalid later
            $this->schoolId, $this->subjects, $this->from, $this->to, $this->perPage,
        );
    }
}

$search = (new EvaluationSearchBuilder())  // readable, any order
    ->school(12)
    ->subjects('math', 'science')
    ->between('2026-09-01', '2026-10-31')
    ->build();
