Command

BehaviourGoF book

A restaurant ticket: the order is written down, so it can wait in line, be retried, or be torn up.

The rule to rememberAn action you want to run later, queue, retry, log or undo → turn the action into an object.

Without it: the pain

The controller runs a 40-second AI analysis. The user waits, the request times out, the work is lost.

With it: the fix

The action becomes a job object. The controller queues it and answers instantly; a worker runs and retries it.

Reach for it when you see

  • Slow work inside an HTTP request
  • "Retry it if the API fails" requirements
  • Undo / redo, or an audit trail of actions

Real job where it fits

After a survey closes, send all responses to an AI service for analysis (slow, can fail).

Before: the code that hurts

public function close(Survey $survey, AiAnalyzer $ai)
{
    $survey->close();
    $analysis = $ai->analyze($survey->responses);   // 40 seconds; timeout = lost
    $survey->saveAnalysis($analysis);
    return back();
}

After: how you implement the Command pattern in PHP

final class AnalyzeSurveyResponses implements ShouldQueue  // the action as an object
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public int $tries = 3;
    public array $backoff = [30, 120, 600];                     // wait longer after each failure

    public function __construct(public readonly int $surveyId) {}  // only data, so it can travel

    public function handle(AiAnalyzer $ai, SurveyRepository $surveys): void   // dependencies at run time
    {
        $survey = $surveys->findOrFail($this->surveyId);
        $surveys->saveAnalysis($survey, $ai->analyze($survey->responses()));
    }

    public function failed(Throwable $e): void                  // after the last retry: never silent
    {
        Log::error('survey.analysis.failed', ['survey' => $this->surveyId, 'error' => $e->getMessage()]);
    }
}

public function close(Survey $survey)
{
    DB::transaction(function () use ($survey) {
        $survey->close();
        AnalyzeSurveyResponses::dispatch($survey->id)->afterCommit();  // queue it, answer now
    });

    return back()->with('status', 'Analysis started.');
}
