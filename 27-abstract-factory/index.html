Chapter 27 of 30

Local vs cloud: storage and queue must always match

Abstract Factory

New ticket

The inspector never got the Ministry export

From Operations

Since we moved the workers to the cloud, the "notify inspector" job fails every time with "file not found". The web server writes the export to its own disk, but the job runs on a cloud worker that has a different disk. Locally everything works, which is why nobody noticed.

Why the quick fix is a trap

Storage and queue are configured separately, so any combination is possible:

the quick fix (we won’t do this)
// bootstrap/app.php: two independent decisions
$app->singleton(FileStorage::class, fn () => getenv('STORAGE') === 's3'
    ? new S3Storage(new S3Client(), 'evalu8-exports')
    : new LocalDiskStorage(__DIR__ . '/../var/storage'));

$app->singleton(Queue::class, fn (Container $c) => getenv('QUEUE') === 'sqs'
    ? new SqsQueue(new SqsClient(), $queueUrl)
    : new DatabaseQueue($c->make(PDO::class)));

// production .env: STORAGE=local, QUEUE=sqs   ← nobody notices until a job runs

The two services only work in matching pairs: local disk with the database queue (one server, the worker can read the disk), or S3 with SQS (many servers, everyone reads S3). The other two combinations look fine in every test and fail only in production.

We want one decision that picks a whole family of services, so a mismatched pair can’t be built at all.

The pattern: Abstract Factory

Remember itSeveral objects must always come from the same family → one factory interface creates each of them, and one concrete factory per family creates only matching ones.

InfrastructureKit is the abstract factory: it has one method per product, storage() and queue(). LocalKit creates the local family (disk + database queue); CloudKit creates the cloud family (S3 + SQS).

The code that uses them, here ExportPublisher, receives a kit and asks it for both services. Because both come from the same kit, they always belong together. The environment chooses the kit once, in one line of the bootstrap.

Compare with Factory Method (chapter 13): that is one method that creates one product and is overridden by subclasses. An Abstract Factory is an object that creates a set of related products.

  1. 1The storage interface

    put() returns a location, not a server path. Whoever reads the file later passes the location back to get().

    src/Storage/FileStorage.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Evalu8\Storage;

interface FileStorage
{
    /** @return string where the file now lives, in a form only this storage understands */
    public function put(string $path, string $contents): string;

    /** @param string $location a value returned by put() */
    public function get(string $location): string;
}

  2. 2Product 1, local family: files on this server’s disk

    Its locations start with disk://: they only mean something on this server.

    src/Storage/LocalDiskStorage.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Evalu8\Storage;

use RuntimeException;

/** Files on this server's disk. Only processes on the same server can read them. */
final readonly class LocalDiskStorage implements FileStorage
{
    public function __construct(private string $directory)
    {
    }

    public function put(string $path, string $contents): string
    {
        $location = rtrim($this->directory, '/') . '/' . ltrim($path, '/');
        if (!is_dir(dirname($location)) && !mkdir(dirname($location), 0775, true)) {
            throw new RuntimeException("Can't create " . dirname($location) . '.');
        }
        if (file_put_contents($location, $contents) === false) {
            throw new RuntimeException("Can't write {$location}.");
        }

        return 'disk://' . ltrim($path, '/');               // a location, not a server path: it is only valid on this server
    }

    public function get(string $location): string
    {
        if (!str_starts_with($location, 'disk://')) {
            throw new RuntimeException("Not a local disk location: {$location}");
        }

        $file = rtrim($this->directory, '/') . '/' . substr($location, strlen('disk://'));
        $contents = @file_get_contents($file);
        if ($contents === false) {
            throw new RuntimeException("File not found on this server: {$location}");
        }

        return $contents;
    }
}

  3. 3Product 1, cloud family: files in S3

    src/Storage/S3Storage.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Evalu8\Storage;

use Aws\S3Client;

/** Files in an S3 bucket, readable from any server that has the bucket's credentials. */
final readonly class S3Storage implements FileStorage
{
    public function __construct(
        private S3Client $s3,
        private string $bucket,
    ) {
    }

    public function put(string $path, string $contents): string
    {
        $this->s3->putObject(['Bucket' => $this->bucket, 'Key' => $path, 'Body' => $contents]);

        return "s3://{$this->bucket}/{$path}";
    }

    public function get(string $location): string
    {
        $key = substr($location, strlen("s3://{$this->bucket}/"));

        return $this->s3->getObject(['Bucket' => $this->bucket, 'Key' => $key])['Body'];
    }
}

  4. 4A stand-in for the AWS SDK’s S3 client

    Same call shape as Aws\S3\S3Client (putObject, getObject), kept in memory so the project runs offline.

    fakes/Aws/S3Client.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Aws;

use RuntimeException;

/**
 * Shaped like the AWS SDK's S3Client::putObject() / getObject(). Objects are kept in memory.
 */
final class S3Client
{
    /** @var array<string, string> "bucket/key" => body */
    private array $objects = [];

    /**
     * @param array{Bucket: string, Key: string, Body: string} $args
     * @return array{ObjectURL: string}
     */
    public function putObject(array $args): array
    {
        $this->objects["{$args['Bucket']}/{$args['Key']}"] = $args['Body'];

        return ['ObjectURL' => "https://{$args['Bucket']}.s3.eu-central-1.amazonaws.com/{$args['Key']}"];
    }

    /**
     * @param array{Bucket: string, Key: string} $args
     * @return array{Body: string}
     */
    public function getObject(array $args): array
    {
        $id = "{$args['Bucket']}/{$args['Key']}";
        if (!isset($this->objects[$id])) {
            throw new RuntimeException("NoSuchKey: {$id}");
        }

        return ['Body' => $this->objects[$id]];
    }
}

  5. 5And for the SQS client

    fakes/Aws/SqsClient.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Aws;

/**
 * Shaped like the AWS SDK's SqsClient::sendMessage() / receiveMessage() / deleteMessage().
 * Messages are kept in memory.
 */
final class SqsClient
{
    /** @var array<string, array<string, string>> queue URL => receipt handle => body */
    private array $queues = [];
    private int $sequence = 0;

    /** @param array{QueueUrl: string, MessageBody: string} $args */
    public function sendMessage(array $args): array
    {
        $this->sequence++;
        $this->queues[$args['QueueUrl']]["rh-{$this->sequence}"] = $args['MessageBody'];

        return ['MessageId' => "msg-{$this->sequence}"];
    }

    /**
     * @param array{QueueUrl: string} $args
     * @return array{Messages?: list<array{ReceiptHandle: string, Body: string}>}
     */
    public function receiveMessage(array $args): array
    {
        foreach ($this->queues[$args['QueueUrl']] ?? [] as $handle => $body) {
            return ['Messages' => [['ReceiptHandle' => $handle, 'Body' => $body]]];
        }

        return [];
    }

    /** @param array{QueueUrl: string, ReceiptHandle: string} $args */
    public function deleteMessage(array $args): void
    {
        unset($this->queues[$args['QueueUrl']][$args['ReceiptHandle']]);
    }
}

  6. 6Product 2, cloud family: a queue on SQS

    It implements the same Queue interface as the database queue from chapter 23, so the worker and the bus don’t change.

    src/Bus/SqsQueue.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Evalu8\Bus;

use Aws\SqsClient;
use LogicException;
use Throwable;

/**
 * The same Queue interface on Amazon SQS, for workers running on other servers.
 * (Attempt counting is left to SQS's redrive policy and dead-letter queue.)
 */
final class SqsQueue implements Queue
{
    /** @var array<int, string> job id => SQS receipt handle */
    private array $handles = [];
    private int $nextId = 1;

    public function __construct(
        private readonly SqsClient $sqs,
        private readonly string $queueUrl,
    ) {
    }

    public function push(ShouldQueue $command): int
    {
        $this->sqs->sendMessage([
            'QueueUrl' => $this->queueUrl,
            'MessageBody' => json_encode(['command' => $command::class, 'payload' => get_object_vars($command)], JSON_THROW_ON_ERROR),
        ]);

        return $this->nextId++;
    }

    public function reserve(): ?Job
    {
        $messages = $this->sqs->receiveMessage(['QueueUrl' => $this->queueUrl])['Messages'] ?? [];
        if (count($messages) === 0) {
            return null;
        }

        /** @var array{command: string, payload: array<string, mixed>} $body */
        $body = json_decode($messages[0]['Body'], true, flags: JSON_THROW_ON_ERROR);
        $class = $body['command'];
        if (!class_exists($class) || !is_subclass_of($class, ShouldQueue::class)) {
            throw new LogicException("Refusing to rebuild [{$class}]: it is not a queueable command.");
        }

        $id = $this->nextId++;
        $this->handles[$id] = $messages[0]['ReceiptHandle'];

        return new Job($id, new $class(...$body['payload']), 0);
    }

    public function complete(Job $job): void
    {
        $this->sqs->deleteMessage(['QueueUrl' => $this->queueUrl, 'ReceiptHandle' => $this->handles[$job->id]]);
        unset($this->handles[$job->id]);
    }

    public function release(Job $job, Throwable $error, bool $final): void
    {
        if ($final) {
            $this->complete($job);                          // SQS would move it to the dead-letter queue
        }
        // otherwise do nothing: SQS makes the message visible again after its timeout
    }
}

  7. 7The abstract factory

    One method per product. Nothing that receives a kit can mix families.

    src/Infrastructure/Kit/InfrastructureKit.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Evalu8\Infrastructure\Kit;

use Evalu8\Bus\Queue;
use Evalu8\Storage\FileStorage;

/**
 * The Abstract Factory: creates a whole family of infrastructure services that work
 * together. Code that receives a kit can never get storage from one family and a queue
 * from another.
 */
interface InfrastructureKit
{
    public function name(): string;

    public function storage(): FileStorage;

    public function queue(): Queue;
}

  8. 8Concrete factory: the local family

    Each product is created once and reused (??=), so the whole app shares one storage and one queue.

    src/Infrastructure/Kit/LocalKit.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Evalu8\Infrastructure\Kit;

use Evalu8\Bus\DatabaseQueue;
use Evalu8\Bus\Queue;
use Evalu8\Storage\FileStorage;
use Evalu8\Storage\LocalDiskStorage;
use PDO;

/**
 * One server: files on its disk, jobs in its database. The worker runs on the same machine,
 * so it can read the files.
 */
final class LocalKit implements InfrastructureKit
{
    private ?FileStorage $storage = null;
    private ?Queue $queue = null;

    public function __construct(
        private readonly string $storageDirectory,
        private readonly PDO $db,
    ) {
    }

    public function name(): string
    {
        return 'local';
    }

    public function storage(): FileStorage
    {
        return $this->storage ??= new LocalDiskStorage($this->storageDirectory);
    }

    public function queue(): Queue
    {
        return $this->queue ??= new DatabaseQueue($this->db);
    }
}

  9. 9Concrete factory: the cloud family

    src/Infrastructure/Kit/CloudKit.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Evalu8\Infrastructure\Kit;

use Aws\S3Client;
use Aws\SqsClient;
use Evalu8\Bus\Queue;
use Evalu8\Bus\SqsQueue;
use Evalu8\Storage\FileStorage;
use Evalu8\Storage\S3Storage;

/**
 * Many servers: files in S3, jobs in SQS. Workers run anywhere and read files from S3.
 */
final class CloudKit implements InfrastructureKit
{
    private ?FileStorage $storage = null;
    private ?Queue $queue = null;

    public function __construct(
        private readonly S3Client $s3,
        private readonly SqsClient $sqs,
        private readonly string $bucket,
        private readonly string $queueUrl,
    ) {
    }

    public function name(): string
    {
        return 'cloud';
    }

    public function storage(): FileStorage
    {
        return $this->storage ??= new S3Storage($this->s3, $this->bucket);
    }

    public function queue(): Queue
    {
        return $this->queue ??= new SqsQueue($this->sqs, $this->queueUrl);
    }
}

  10. 10The client: store the file, then queue the follow-up

    src/Reporting/ExportPublisher.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Evalu8\Reporting;

use Evalu8\Infrastructure\Kit\InfrastructureKit;

/**
 * The client of the Abstract Factory: it uses the storage and the queue, and because both
 * come from the same kit, they always belong together.
 */
final readonly class ExportPublisher
{
    public function __construct(private InfrastructureKit $kit)
    {
    }

    public function publish(string $term, string $csv): string
    {
        $location = $this->kit->storage()->put("exports/ministry-{$term}.csv", $csv);
        $this->kit->queue()->push(new NotifyInspector($term, $location));

        return $location;
    }
}

  12. 12Its handler reads the file back

    On the worker, the storage it receives is the same family that wrote the file, so the location always resolves.

    src/Reporting/NotifyInspectorHandler.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Evalu8\Reporting;

use Evalu8\Logging\Logger;
use Evalu8\Storage\FileStorage;

final readonly class NotifyInspectorHandler
{
    public function __construct(
        private FileStorage $storage,                       // must be the storage that wrote the file
        private Logger $logger,
    ) {
    }

    public function handle(NotifyInspector $command): void
    {
        $csv = $this->storage->get($command->location);
        $rows = count(explode("\n", trim($csv))) - 1;

        $this->logger->info('inspector notified', ['term' => $command->term, 'rows' => $rows, 'file' => $command->location]);
    }
}

  15. 15Run it with both families

    bin/publish-export.phpnew fileGitHub
    <?php

declare(strict_types=1);

/*
 * Evalu8, chapter 27: storage and queue always come from the same infrastructure family.
 *
 *     composer dump-autoload
 *     php bin/publish-export.php
 *
 * In production one environment variable picks the family: EVALU8_INFRA=local or EVALU8_INFRA=cloud.
 * This demo runs both, one after the other.
 */

use Evalu8\Bus\Worker;
use Evalu8\Container\Container;
use Evalu8\Demo\SampleData;
use Evalu8\Domain\ResponseRepository;
use Evalu8\Infrastructure\Kit\InfrastructureKit;
use Evalu8\Reporting\ExportPublisher;
use Evalu8\Reporting\TermReport;

const CURRENT_TERM = '2026-T1';

foreach (['local', 'cloud'] as $infrastructure) {
    putenv("EVALU8_INFRA={$infrastructure}");

    /** @var Container $app */
    $app = require __DIR__ . '/../bootstrap/app.php';
    echo "\n== {$app->make(InfrastructureKit::class)->name()} ==\n";
    SampleData::loadAnswers($app->make(ResponseRepository::class), CURRENT_TERM);

    $csv = "teacher,score\n";
    foreach ($app->make(TermReport::class)->results(CURRENT_TERM) as $result) {
        $csv .= "{$result->teacher->name}," . ($result->score === null ? '' : round($result->score, 2)) . "\n";
    }

    // The web request: store the file and queue the follow-up job. One kit, so they match.
    $location = $app->make(ExportPublisher::class)->publish(CURRENT_TERM, $csv);
    echo "Stored at: {$location}\n";

    // The worker (on the same server for "local", on any server for "cloud") reads the file back.
    $app->make(Worker::class)->runUntilEmpty();
}

How Laravel does it

Laravel configures disks (FILESYSTEM_DISK) and queues (QUEUE_CONNECTION) separately, so the mismatch in this ticket is possible there too. Keep them in one place per environment, or bind your own kit in a service provider.

Inside the framework, every database connection is an abstract factory: a connection creates its own matching query grammar, schema grammar and post-processor, so MySQL SQL can never be sent to PostgreSQL.

Laravel
// Illuminate\Database\MySqlConnection (simplified): one family of products
class MySqlConnection extends Connection
{
    protected function getDefaultQueryGrammar(): MySqlGrammar
    {
        return new MySqlGrammar($this);
    }

    protected function getDefaultSchemaGrammar(): MySqlSchemaGrammar
    {
        return new MySqlSchemaGrammar($this);
    }

    protected function getDefaultPostProcessor(): MySqlProcessor
    {
        return new MySqlProcessor();
    }
}
// PostgresConnection and SQLiteConnection create their own matching set.

Check yourself

Answer in your head, then open the answer.

A third environment, "on-premise", uses MinIO for files and RabbitMQ for jobs. What do you add?

One new kit (OnPremiseKit implements InfrastructureKit) that creates the MinIO storage and the RabbitMQ queue, and one more match arm in the bootstrap. ExportPublisher and the worker don’t change.

How is this different from the Factory Method in chapter 13?

Factory Method is one overridable method that creates one product. Abstract Factory is an object with several creation methods whose products must match each other.

Why does LocalDiskStorage return disk://exports/… instead of the full path?

A location must be passed back to the same storage, not opened directly. A server path would invite code to read the file itself, which only works on that one server.
