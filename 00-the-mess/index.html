Chapter 0 of 30

The code we inherited

You just joined the team behind Evalu8. Schools use it to evaluate their teachers: students, colleagues (peers) and the principal answer a short survey, each answer is a score from 1 to 5, and at the end of the term the app produces a report, emails every teacher their result and sends a CSV to the Ministry of Education.

Everything lives in one PHP file. It runs, it has been "working" for two years, and nobody wants to touch it. In this course we will touch it: one real problem per chapter, fixed with the design pattern that fits it. By the last chapter, the same app will use every pattern from the Gang of Four book plus the modern ones every PHP framework relies on.

Before changing anything, we read the code and run it.

    <?php

declare(strict_types=1);

/*
 * Evalu8: the code as we found it.
 *
 * One script does everything: it saves answers, prints the term report,
 * emails each teacher a summary and exports a CSV for the Ministry.
 * It "works". Run it and read the output carefully.
 *
 *     php evaluations.php
 */

$db = new PDO('sqlite::memory:');
$db->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$db->setAttribute(PDO::ATTR_DEFAULT_FETCH_MODE, PDO::FETCH_ASSOC);

$db->exec('CREATE TABLE teachers (id INTEGER PRIMARY KEY, name TEXT, email TEXT, school TEXT)');
$db->exec('CREATE TABLE responses (id INTEGER PRIMARY KEY, teacher_id INTEGER, role TEXT, score, comment TEXT)');

$db->exec("INSERT INTO teachers (id, name, email, school) VALUES
    (1, 'Hany Mostafa', 'hany@smouha.edu.eg', 'Smouha'),
    (2, 'Nadia Fawzy', '', 'Smouha'),
    (3, 'Karim Adel', 'karim@miami.edu.eg', 'Miami')");

// ── Answers coming in from the survey form (scores are 1 to 5) ──
$submitted = [
    ['teacher_id' => 1, 'role' => 'student', 'score' => '5', 'comment' => 'Explains clearly'],
    ['teacher_id' => 1, 'role' => 'student', 'score' => '4', 'comment' => ''],
    ['teacher_id' => 1, 'role' => 'principal', 'score' => '140', 'comment' => 'typo: meant 4'],
    ['teacher_id' => 2, 'role' => 'student', 'score' => '3', 'comment' => 'Starts late'],
    ['teacher_id' => 2, 'role' => 'peer', 'score' => 'five', 'comment' => ''],
    ['teacher_id' => 3, 'role' => 'studnet', 'score' => '2', 'comment' => 'Too fast'],
    ['teacher_id' => 3, 'role' => 'peer', 'score' => '4', 'comment' => ''],
];

foreach ($submitted as $answer) {
    $db->exec("INSERT INTO responses (teacher_id, role, score, comment) VALUES ("
        . $answer['teacher_id'] . ", '" . $answer['role'] . "', '" . $answer['score'] . "', '"
        . $answer['comment'] . "')");
}

// ── The term report ──
echo "TERM REPORT\n";
$teachers = $db->query('SELECT * FROM teachers')->fetchAll();
foreach ($teachers as $teacher) {
    $rows = $db->query('SELECT * FROM responses WHERE teacher_id = ' . $teacher['id'])->fetchAll();
    $total = 0;
    foreach ($rows as $row) {
        $total += (float) $row['score'];
    }
    $average = count($rows) > 0 ? $total / count($rows) : 0;
    echo str_pad($teacher['name'], 14) . ' average ' . number_format($average, 2) . "\n";
}

// ── Email each teacher a summary ──
echo "\nEMAILS\n";
foreach ($teachers as $teacher) {
    $rows = $db->query('SELECT * FROM responses WHERE teacher_id = ' . $teacher['id'])->fetchAll();
    $total = 0;
    foreach ($rows as $row) {
        $total += (float) $row['score'];
    }
    $average = count($rows) > 0 ? $total / count($rows) : 0;
    echo "To: <{$teacher['email']}> Your average this term is " . number_format($average, 2) . "\n";
}

// ── CSV export for the Ministry ──
echo "\nMINISTRY CSV\n";
echo "teacher,school,responses,average\n";
foreach ($teachers as $teacher) {
    $rows = $db->query('SELECT score FROM responses WHERE teacher_id = ' . $teacher['id'])->fetchAll();
    $sum = 0;
    foreach ($rows as $row) {
        $sum += (int) $row['score'];
    }
    $average = count($rows) > 0 ? round($sum / count($rows), 2) : 0;
    echo "{$teacher['name']},{$teacher['school']}," . count($rows) . ",{$average}\n";
}

What’s wrong with it

  1. Impossible numbers

    Hany’s average is 49.67 on a 1–5 scale, because a principal typed 140. Nadia’s is 1.50 although her student gave her 3: the peer’s answer five was stored as text and counted as 0. A role spelled studnet was stored too. The script accepts whatever arrives.

    Fixed in chapter 1: Value Object

  2. An email to nobody

    Nadia has no email address, so the script "sent" her result to <>. Nothing failed, so nobody noticed.

    Fixed in chapter 1: Value Object

  3. The same SQL, three times

    The report, the emails and the CSV each run their own SELECT ... WHERE teacher_id = .... Any new rule (for example, "only this term") must be added to every copy. The INSERT is also built by joining strings, so a comment like Didn’t use the lab breaks it.

    Fixed in chapter 2: Repository, Data Mapper vs Active Record

  4. The scoring rule is copied, and the copies already disagree

    The average is calculated three times. The report and the emails use (float), the CSV uses (int) and rounds. Schools are also starting to ask for their own scoring methods, and there is no place to put them.

    Fixed in chapter 3: Strategy

None of these problems needs a framework to fix. Each one needs one idea: a pattern. We start with the most dangerous one: wrong numbers that look real.
