Guest charged €450.29 for a €450.30 stay

Money in cents, Currency, Eloquent casts, CarbonImmutable

Value Object

#supportMonday 09:12

Mona · supportA guest booked the Nyhavn flat for 3 nights at €150.10. The confirmation email says €450.30, but Stripe charged €450.29. She’s asking if we’re scamming her. It’s the third complaint this month, always one cent.

The broken code

app/Http/Controllers/CheckoutController.php (before)the bug
$nightly = $property->nightly_rate;                 // 150.10, a DECIMAL column read as float
$total = $nightly * $nights;                        // 450.3 ... or is it?

$stripe->paymentIntents->create([
    'amount' => (int) ($total * 100),               // Stripe wants cents
    'currency' => 'eur',
]);

Run it in Tinker:

php artisan tinker
> 150.10 * 3
= 450.29999999999995
> (int) (150.10 * 3 * 100)
= 45029

A float is stored in binary, and 150.10 has no exact binary form, just as 1/3 has no exact decimal form. The multiplication lands a hair below 450.30, and (int) cuts off the rest instead of rounding. The email rounded for display, Stripe got the cut-off value.

The fix, part 1: integers, in cents

Money is never a float. It is a whole number in the currency’s smallest unit: €150.10 is stored as 15010. That’s why the properties table has nightly_rate_cents, an unsigned integer. Integer arithmetic is exact: 15010 * 3 is 45030, every time.

That fixes the cent. But the amount is now a bare int, with its currency in another column, and nothing stops this:

anywhere in the appthe bug
$total = $flat->nightly_rate_cents + $loft->nightly_rate_cents;   // EUR cents + EGP piastres = a meaningless number

The number and its currency have to travel together, as one thing.

The fix, part 2: one object for amount and currency

The currency knows its decimals

Not every currency has cents: 15010 euro cents is €150.10, but 15010 yen is ¥15,010. The enum lists the currencies Nordic Stays accepts, and an unknown code fails the moment it is read.

app/Money/Currency.php
<?php

namespace App\Money;

enum Currency: string
{
    case EUR = 'EUR';
    case USD = 'USD';
    case EGP = 'EGP';
    case JPY = 'JPY';

    /** Digits after the decimal point (ISO 4217). */
    public function minorUnits(): int
    {
        return match ($this) {
            self::JPY => 0,
            default => 2,
        };
    }
}

Money

Three choices do the work. readonly: a Money can’t change after it’s created, so one passed around the app can’t be modified behind your back. A private constructor: of() is the only way in, and it always resolves the currency. And no float, anywhere in a calculation.

app/Money/Money.php
<?php

namespace App\Money;

use Illuminate\Support\Number;
use LogicException;

final readonly class Money
{
    private function __construct(
        public int $amount,                                     // in minor units: cents, piastres, yen
        public Currency $currency,
    ) {
    }

    public static function of(int $amount, Currency|string $currency): self
    {
        return new self($amount, $currency instanceof Currency ? $currency : Currency::from($currency));
    }

    public function add(self $other): self
    {
        $this->assertSameCurrency($other);

        return new self($this->amount + $other->amount, $this->currency);   // a new object; $this never changes
    }

    public function times(int $factor): self
    {
        return new self($this->amount * $factor, $this->currency);
    }

    public function equals(self $other): bool
    {
        return $this->amount === $other->amount && $this->currency === $other->currency;
    }

    /** For people only (emails, screens). Never feed this back into a calculation. */
    public function format(): string
    {
        return Number::currency($this->amount / 10 ** $this->currency->minorUnits(), $this->currency->value);
    }

    private function assertSameCurrency(self $other): void
    {
        if ($other->currency !== $this->currency) {
            throw new LogicException("Can't combine {$this->currency->value} with {$other->currency->value}.");
        }
    }
}

Using it

A cast: the model hands out Money

One Money attribute is built from two columns: the amount and currency. So set() returns both.

app/Casts/MoneyCast.php
<?php

namespace App\Casts;

use App\Money\Money;
use Illuminate\Contracts\Database\Eloquent\CastsAttributes;
use Illuminate\Database\Eloquent\Model;
use InvalidArgumentException;

/** @implements CastsAttributes<Money, Money> */
final class MoneyCast implements CastsAttributes
{
    public function __construct(private string $amountColumn)  // e.g. "nightly_rate_cents"
    {
    }

    /** @param array<string, mixed> $attributes */
    public function get(Model $model, string $key, mixed $value, array $attributes): Money
    {
        return Money::of((int) $attributes[$this->amountColumn], $attributes['currency']);
    }

    /**
     * @param array<string, mixed> $attributes
     * @return array<string, int|string>
     */
    public function set(Model $model, string $key, mixed $value, array $attributes): array
    {
        if (! $value instanceof Money) {
            throw new InvalidArgumentException("{$key} must be set with a Money object.");
        }

        return [$this->amountColumn => $value->amount, 'currency' => $value->currency->value];
    }
}

The charge, fixed

app/Http/Controllers/CheckoutController.php (after)
$total = $property->nightly_rate->times($nights);    // Money(45030, EUR)

$stripe->paymentIntents->create([
    'amount' => $total->amount,                         // 45030: already in minor units, nothing to convert
    'currency' => strtolower($total->currency->value),
]);

The email shows $total->format() (€450.30) and Stripe charges 45030. Both come from the same object, so they can’t disagree again.

You just wrote the Value Object pattern

Value ObjectA small object defined only by its value: immutable, and valid from the moment it exists.

  • Two Money(45030, EUR) objects are equal even though they are different objects. That’s why equals() compares values, not identity.
  • It protects its own rules: no mixing currencies, no floats, no changing after creation.
  • It comes from Domain-Driven Design (Eric Evans, 2003), not from the Gang of Four book.

When not to use it

  • A value with no rules, like a guest’s name. A string is enough.
  • Something with its own identity that changes over time, like a booking. That’s an entity (a model), not a value.

Laravel does the same

Every date Laravel gives you is a value object: CarbonImmutable, switched on in the foundation with Date::use(CarbonImmutable::class).

php artisan tinker
$checkIn = CarbonImmutable::parse('2027-07-01');
$checkOut = $checkIn->addDays(3);         // a NEW object

$checkIn->toDateString();                 // still "2027-07-01"

With the mutable Carbon, addDays() would have moved $checkIn too: the same kind of hidden change that readonly rules out for Money.

How Eloquent calls your cast

The cast runs the first time you read the attribute, and the result is cached on the model, so $property->nightly_rate builds one Money per model, not one per read.

Illuminate/Database/Eloquent/Concerns/HasAttributes.php (simplified)
protected function getClassCastableAttributeValue($key, $value)
{
    $caster = $this->resolveCasterClass($key);            // new MoneyCast('nightly_rate_cents')

    return $this->classCastCache[$key] ??= $caster->get($this, $key, $value, $this->attributes);
}
TestsMoney arithmetic, currencies, formatting and the cast
tests/Unit/MoneyTest.php
<?php

use App\Money\Money;

it('multiplies exactly, with no lost cent', function () {
    expect(Money::of(15_010, 'EUR')->times(3)->amount)->toBe(45_030);   // the incident
});

it('never changes the original', function () {
    $nightly = Money::of(15_010, 'EUR');

    $nightly->times(3);

    expect($nightly->amount)->toBe(15_010);
});

it('refuses to mix currencies', function () {
    Money::of(100, 'EUR')->add(Money::of(100, 'EGP'));
})->throws(LogicException::class, "Can't combine EUR with EGP.");

it('compares by value', function () {
    expect(Money::of(45_030, 'EUR')->equals(Money::of(45_030, 'EUR')))->toBeTrue()
        ->and(Money::of(45_030, 'EUR')->equals(Money::of(45_030, 'USD')))->toBeFalse();
});

it('formats with the currency’s own decimals', function (int $amount, string $currency, string $shown) {
    expect(Money::of($amount, $currency)->format())->toBe($shown);
})->with([
    [45_030, 'EUR', '€450.30'],
    [15_010, 'JPY', '¥15,010'],
]);
tests/Feature/MoneyCastTest.php
<?php

use App\Models\Property;

it('reads the nightly rate as Money', function () {

        ->nightly_rate_cents->toBe(9_900)
        ->currency->toBe('USD');
