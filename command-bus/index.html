Command Bus

BehaviourNot in the book

A dispatch desk: you hand in a form, and the desk knows which department handles it.

The rule to rememberSplit "what to do" (a data object) from "how" (a handler) → the same action runs from web, CLI or queue, with shared rules around it.

Without it: the pain

The business logic lives in a controller. The scheduler and the import need it too, so it gets copied or called through HTTP.

With it: the fix

RecalculateSchoolStats is data; its handler holds the logic. Any entry point dispatches the same command.

Reach for it when you see

  • The same business action needed from HTTP, CLI and queue
  • Fat controllers full of business logic
  • You want one place for transactions / logging around every action

Real job where it fits

"Recalculate school statistics" runs from an admin button, a nightly schedule, and after every import.

Before: the code that hurts

final class StatsController
{
    public function recalculate(School $school, StatsCalculator $calc, StatsRepository $stats)
    {
        $stats->save($school->id, $calc->forSchool($school->id));   // the scheduler and the importer
        return back();                                               // need this too... copy it?
    }
}

After: how you implement the Command Bus pattern in PHP

final class RecalculateSchoolStats  // the command: only data
{
    public function __construct(public readonly int $schoolId) {}
}

final class RecalculateSchoolStatsHandler  // the handler: logic + dependencies
{
    public function __construct(private StatsCalculator $calc, private StatsRepository $stats) {}

    public function handle(RecalculateSchoolStats $command): void
    {
        $this->stats->save($command->schoolId, $this->calc->forSchool($command->schoolId));
    }
}

final class CommandBus
{
    /** @param array<class-string, class-string> $handlers */
    public function __construct(
        private \Psr\Container\ContainerInterface $container,
        private array $handlers,
    ) {}

    public function dispatch(object $command): mixed
    {
        $handler = $this->handlers[$command::class]
            ?? throw new LogicException('No handler for ' . $command::class);   // wiring bugs fail loudly

        return DB::transaction(  // one place for shared rules
            fn () => $this->container->get($handler)->handle($command)
        );
    }
}

// Admin button, nightly schedule, after an import — the same line:
$bus->dispatch(new RecalculateSchoolStats($schoolId));
