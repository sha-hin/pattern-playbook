Iterator

BehaviourGoF book

A playlist's Next button: you don't care if songs are on disk, in the cloud or on a CD.

The rule to rememberCallers need to loop over data, but how it’s stored or fetched may change → give them items one at a time, hide the rest.

Without it: the pain

Every caller of the CRM API writes its own page=1, page=2, has_more loop, and loads everything into memory.

With it: the fix

One iterable class hides the pagination and yields one customer at a time. Callers just foreach.

Reach for it when you see

  • The same pagination / chunking loop copied in many places
  • Loading 100K rows into an array before processing
  • Callers know the internal shape of your collection

Real job where it fits

A CRM API returns 100 customers per page. You sync 80,000 customers every night.

Before: the code that hurts

// copied in 3 jobs:
$page = 1; $all = [];
do {
    $response = Http::get($crm.'/customers', ['page' => $page++]);
    $all = array_merge($all, $response->json('data'));   // 80,000 rows in memory
} while ($response->json('meta.has_more'));

After: how you implement the Iterator pattern in PHP

final class CrmCustomers implements IteratorAggregate  // hides HOW they're fetched
{
    public function __construct(private \Illuminate\Http\Client\PendingRequest $http) {}

    public function getIterator(): Generator
    {
        $page = 1;

        do {
            $response = $this->http
                ->get('/customers', ['page' => $page++, 'per_page' => 100])
                ->throw();                                     // 4xx/5xx = exception, not empty data

            foreach ($response->json('data') as $customer) {
                yield $customer;  // one at a time, flat memory
            }
        } while ($response->json('meta.has_more') === true);
    }
}

$customers = new CrmCustomers(
    Http::baseUrl(config('services.crm.url'))->withToken(config('services.crm.token'))->retry(3, 500),
);

foreach ($customers as $customer) {  // pagination is invisible here
    Customer::updateOrCreate(['crm_id' => $customer['id']], ['email' => $customer['email']]);
}
