Laravel Facade (static proxy)

StructureNot in the book

A speed-dial button: one press, and it calls the real number for you.

The rule to rememberCache::get() is a static shortcut that FORWARDS to one object in the container. It is a Proxy, not the GoF Facade.

Without it: the pain

People think Cache::get() is static code that can’t be swapped, call it "the Facade pattern", and hide dependencies inside domain classes.

With it: the fix

Know the mechanism: __callStatic → container → the real object. Use it in routes and scripts; inject the real class in your own services.

Reach for it when you see

  • You want a short global shortcut for a service (routes, Blade, scripts)
  • Someone calls Cache:: "the Facade pattern"
  • A domain class full of static calls that tests can’t see

Real job where it fits

You built an AiManager and want a short Ai:: shortcut in Blade views and Artisan commands.

Before: the code that hurts

// repeated in every Blade view, route file and Artisan command:
app(AiManager::class)->driver()->summarize($text);

Build it yourself: the full Laravel Facade (static proxy) pattern in plain PHP

No framework. Every part of the pattern is here, labelled with its role. Copy it, run it, change it.

Proxy baseFacade turns a static call into a call on a real object
Concrete proxyCache names which service it stands for
Real subjectArrayCache the one real object, living in the container
ContainerServiceContainer where the real object comes from
<?php

declare(strict_types=1);

final class ArrayCache  // Real subject: the actual service
{
    /** @var array<string, mixed> */
    private array $items = [];

    public function put(string $key, mixed $value): void
    {
        $this->items[$key] = $value;
    }

    public function get(string $key, mixed $default = null): mixed
    {
        return $this->items[$key] ?? $default;
    }
}

final class ServiceContainer                                    // a tiny container (see the DI Container card)
{
    /** @var array<string, Closure(): object> */
    private array $factories = [];

    /** @var array<string, object> */
    private array $instances = [];

    public function singleton(string $id, Closure $factory): void
    {
        $this->factories[$id] = $factory;
    }

    public function make(string $id): object
    {
        return $this->instances[$id] ??= ($this->factories[$id] ?? throw new RuntimeException("Nothing bound for [{$id}]."))();
    }

    public function swap(string $id, object $instance): void   // used by tests
    {
        $this->instances[$id] = $instance;
    }
}

abstract class Facade  // Proxy base
{
    private static ?ServiceContainer $container = null;

    public static function setContainer(ServiceContainer $container): void
    {
        self::$container = $container;
    }

    /** The container id of the real object behind this shortcut. */
    abstract protected static function accessor(): string;

    /** @param list<mixed> $arguments */
    public static function __callStatic(string $method, array $arguments): mixed  // PHP calls this for Cache::anything()
    {
        $container = self::$container ?? throw new RuntimeException('Facade container not set.');
        $target = $container->make(static::accessor());  // find the ONE real object

        if (!method_exists($target, $method)) {
            throw new BadMethodCallException(static::class . "::{$method}() does not exist.");
        }

        return $target->{$method}(...$arguments);  // forward the call, unchanged
    }
}

final class Cache extends Facade  // Concrete proxy
{
    protected static function accessor(): string
    {
        return 'cache';
    }
}

// ── Bootstrapping (what the framework does for you) ─────────────────────
$container = new ServiceContainer();
$container->singleton('cache', fn () => new ArrayCache());
Facade::setContainer($container);

// ── The static-looking call is a normal method call on one object ──────
Cache::put('menu', ['Margherita', 'Pepperoni']);
echo implode(', ', Cache::get('menu')), PHP_EOL;
echo 'Same object? ', var_export($container->make('cache')->get('menu') === Cache::get('menu'), true), PHP_EOL;

// In a test, swap the real object for a fake one: no static code to fight with.
$container->swap('cache', new ArrayCache());
echo 'After swap: ', var_export(Cache::get('menu'), true), PHP_EOL;

In a real Laravel project

The same pattern the way you would write it at work, using what the framework already gives you.

// How it works (simplified):
abstract class Facade
{
    abstract protected static function accessor(): string;

    public static function __callStatic(string $method, array $args): mixed  // PHP calls this for Ai::anything()
    {
        return app(static::accessor())->{$method}(...$args);  // forward to the ONE real object
    }
}

// The Laravel way, for your own service:
final class Ai extends \Illuminate\Support\Facades\Facade
{
    protected static function getFacadeAccessor(): string
    {
        return AiManager::class;
    }
}

Ai::driver()->summarize($text);          // = app(AiManager::class)->driver()->summarize($text)

// In tests:
Ai::shouldReceive('driver->summarize')->andReturn('short summary');

// In your OWN service classes, prefer the visible dependency:
public function __construct(private AiManager $ai) {}

How Laravel builds it inside: Illuminate\Support\Facades\Facade::__callStatic() calls getFacadeRoot(), which resolves getFacadeAccessor() from the container (and caches it), then forwards the call. Facade::swap() and Cache::shouldReceive() replace that object in tests.
