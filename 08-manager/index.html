Manager / Driver

New ticket

Pick the AI provider from config, not from code

From Omar Hassan, DevOps

Laptops run Ollama; production may use OpenAI for schools that allow it; the quality team wants a script that compares two providers on the same comments. Today every switch is a code change in bootstrap/app.php, and the OpenAI client is created even when it isn’t used (so every laptop needs an API key).

Why the quick fix is a trap

The quick fix is an if on the environment:

the quick fix (we won’t do this)
if (getenv('APP_ENV') === 'production') {
    $analyzer = new OpenAiCommentAnalyzer(new OpenAI\Client(getenv('OPENAI_API_KEY')));
} else {
    $analyzer = new OllamaCommentAnalyzer(new Ollama\Client('http://localhost:11434'));
}

// ...and the compare script builds both, with its own copy of the same code.

Environment names leak into code, the compare script copies the construction logic, and a missing setting is discovered deep inside a request instead of with a clear message.

What we want: ask for a provider by name (ollama, openai), get the default from config, build each one only when it is first needed, and reuse it after that.

The pattern: Manager / Driver

Remember itSeveral interchangeable backends chosen by name → one manager builds a driver by name on first use, caches it, and takes the default from config.

AnalyzerManager::driver() returns the default driver from config/ai.php; driver('openai') returns a named one. The first call builds it; later calls return the same object.

A missing setting fails with a message naming the driver and the key. extend() adds new drivers from outside, without editing the manager.

This is not a Gang of Four pattern: it is how Laravel organises every swappable service (cache stores, mailers, filesystems, queues, hashing). Inside, it combines a factory (build by name) with a cache of built instances.

  3. 3The manager

    driver() uses ??= to build a driver only if it isn’t in $drivers yet. create() checks drivers added with extend() first, then the built-in ones. required() turns a missing setting into a precise message.

    src/Analysis/AnalyzerManager.phpnew fileGitHub
    <?php

declare(strict_types=1);

namespace Evalu8\Analysis;

use Closure;
use Ollama\Client as OllamaClient;
use OpenAI\Client as OpenAiClient;

/**
 * The Manager: hands out comment analyzers ("drivers") by name.
 *
 * - driver()          the default driver from config
 * - driver('openai')  a specific one
 * Each driver is built the first time it is asked for, then reused.
 */
final class AnalyzerManager
{
    /** @var array<string, CommentAnalyzer> drivers already built */
    private array $drivers = [];

    /** @var array<string, Closure(array<string, string>): CommentAnalyzer> drivers added with extend() */
    private array $customCreators = [];

    /**
     * @param array{default: string, drivers: array<string, array<string, string>>} $config
     */
    public function __construct(private readonly array $config)
    {
    }

    public function driver(?string $name = null): CommentAnalyzer
    {
        $name ??= $this->config['default'];

        return $this->drivers[$name] ??= $this->create($name);
    }

    /**
     * Registers another driver without editing this class.
     *
     * @param Closure(array<string, string>): CommentAnalyzer $creator receives the driver's config
     */
    public function extend(string $name, Closure $creator): void
    {
        $this->customCreators[$name] = $creator;
        unset($this->drivers[$name]);
    }

    private function create(string $name): CommentAnalyzer
    {
        $config = $this->config['drivers'][$name] ?? [];

        if (isset($this->customCreators[$name])) {
            return ($this->customCreators[$name])($config);
        }

        return match ($name) {
            'ollama' => $this->createOllama($config),
            'openai' => $this->createOpenAi($config),
            default => throw new UnknownDriver(
                "Comment analysis driver \"{$name}\" is not supported. Available: "
                . implode(', ', ['ollama', 'openai', ...array_keys($this->customCreators)]) . '.'
            ),
        };
    }

    /** @param array<string, string> $config */
    private function createOllama(array $config): CommentAnalyzer
    {
        return new OllamaCommentAnalyzer(
            new OllamaClient($this->required($config, 'host', 'ollama')),
            $this->required($config, 'model', 'ollama'),
        );
    }

    /** @param array<string, string> $config */
    private function createOpenAi(array $config): CommentAnalyzer
    {
        return new OpenAiCommentAnalyzer(
            new OpenAiClient($this->required($config, 'api_key', 'openai')),
            $this->required($config, 'model', 'openai'),
        );
    }

    /** @param array<string, string> $config */
    private function required(array $config, string $key, string $driver): string
    {
        if (!isset($config[$key]) || $config[$key] === '') {
            throw new UnknownDriver("The \"{$driver}\" driver needs \"{$key}\" in config/ai.php (or its environment variable).");
        }

        return $config[$key];
    }
}

How Laravel does it

This is Laravel’s Illuminate\Support\Manager in miniature. Cache::store('redis'), Mail::mailer('ses') and Storage::disk('s3') are all managers: a default from config, drivers by name, built once, and extend() for custom drivers.

Laravel
// Laravel's managers work exactly like AnalyzerManager:
Cache::store();             // the default store from config/cache.php
Cache::store('redis');      // a named one, built once

// Adding your own driver, e.g. in AppServiceProvider::boot():
Cache::extend('mongo', fn (Application $app) => Cache::repository(new MongoStore(/* ... */)));

Check yourself

Answer in your head, then open the answer.

Why is the OpenAI client no longer created on developers’ laptops?

Drivers are built on first use. If nothing asks for driver('openai'), its client is never created and no key is needed.

How do you add an Anthropic or Gemini driver without editing AnalyzerManager?

Call $manager->extend('gemini', fn (array $config) => new GeminiCommentAnalyzer(...)) during bootstrap.

What does the manager add on top of a Simple Factory?

A default from config, lookup by name, and caching: each driver is built once and reused.

The model takes seconds per teacher, the report runs twice a day with the same comments, and the server sometimes times out.
