Template Method

BehaviourGoF book

A recipe card with blanks: the steps are printed, you fill in "filling".

The rule to rememberSeveral classes run the same steps in the same order, only some steps differ → parent locks the order, children fill the gaps.

Without it: the pain

3 importers copy the same 5 steps. A fix to validation is made in one and forgotten in the others.

With it: the fix

One parent with a final import(). Each importer only writes the 2 steps that differ.

Reach for it when you see

  • Several classes with near-identical methods, small differences inside
  • A bug fix that had to be copied to 3 classes
  • Someone skipped a step (validation, logging) in one copy

Real job where it fits

Grades arrive from 3 school systems: different file format and column names, same import process.

Before: the code that hurts

final class SystemAImport { public function import($file) { /* read, map, validate, save, log */ } }
final class SystemBImport { public function import($file) { /* read, map, validate, save, log */ } }
final class SystemCImport { public function import($file) { /* read, map, validate, save */ } }  // forgot log

After: how you implement the Template Method pattern in PHP

abstract class GradeImport
{
    final public function import(string $path): int  // the locked recipe
    {
        $raw  = $this->read($path);                            // differs
        $rows = array_map(fn (array $r) => $this->map($r), $raw);  // differs
        $this->validate($rows);                                // same for all
        DB::transaction(fn () => Grade::insert($rows));        // same for all
        Log::info('grades.imported', ['source' => static::class, 'rows' => count($rows)]);
        return count($rows);
    }

    abstract protected function read(string $path): array;  // must fill in
    abstract protected function map(array $row): array;  // must fill in

    private function validate(array $rows): void
    {
        foreach ($rows as $i => $row) {
            if (! is_numeric($row['score']) || $row['score'] < 0 || $row['score'] > 100) {
                throw new InvalidImport("Row {$i}: score must be 0–100.");
            }
        }
    }
}

final class SystemAImport extends GradeImport
{
    protected function read(string $path): array { return array_map('str_getcsv', file($path)); }
    protected function map(array $row): array    { return ['student_id' => $row[0], 'score' => $row[2]]; }
}
