Composite

StructureGoF book

Folders and files: a folder's size is the sum of what's inside, and folders can hold folders.

The rule to rememberYour data is a tree (parts inside wholes, any depth) → items and groups share one interface; a group asks its children.

Without it: the pain

Every function over the survey checks "is this a section or a question?" and recurses by hand.

With it: the fix

Section and Question both answer maxScore(). A section just asks its children. Depth stops mattering.

Reach for it when you see

  • instanceof checks to tell a group from an item
  • Recursive functions copied for every calculation
  • "Groups can contain groups" in the requirements

Real job where it fits

A survey has sections, sub-sections and questions. You need the max score, the question count, the rendering.

Before: the code that hurts

function maxScore(array $nodes): int {
    $total = 0;
    foreach ($nodes as $node) {
        if ($node instanceof Section) { $total += maxScore($node->children); }   // and again in
        else { $total += $node->points; }                                        // countQuestions(),
    }                                                                            // render(), export()...
    return $total;
}

After: how you implement the Composite pattern in PHP

interface SurveyNode  // one shape for items and groups
{
    public function maxScore(): int;
}

final class Question implements SurveyNode                // a leaf
{
    public function __construct(public readonly string $text, private int $points) {}
    public function maxScore(): int { return $this->points; }
}

final class Section implements SurveyNode                 // a group of nodes
{
    /** @var list<SurveyNode> */
    private array $children = [];

    public function __construct(public readonly string $title) {}

    public function add(SurveyNode $node): self { $this->children[] = $node; return $this; }

    public function maxScore(): int
    {
        return array_sum(array_map(
            fn (SurveyNode $child) => $child->maxScore(),  // no instanceof: just ask
            $this->children,
        ));
    }
}

$survey = (new Section('Teacher evaluation'))
    ->add((new Section('Classroom'))
        ->add(new Question('Explains clearly', 5))
        ->add(new Question('Manages time', 5)))
    ->add(new Question('Overall', 10));

$survey->maxScore();   // 20, at any depth
