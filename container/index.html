DI Container

CreationNot in the book

A wall socket: your laptop doesn't build a power plant, it just plugs in.

The rule to rememberA class needs services → ask for them in the constructor; one place (the container) decides what you get.

Without it: the pain

The class builds its own mailer with new and env(). You can't test it without sending real emails.

With it: the fix

The class lists what it needs. The container passes them in; a test passes fakes.

Reach for it when you see

  • new SomeService() or Something::instance() inside methods
  • Tests that send real emails / hit real APIs
  • "Only one" handled by a static Singleton

Real job where it fits

An InvoiceSender needs a mailer and a logger. In tests you want a fake mailer.

Before: the code that hurts

final class InvoiceSender
{
    public function send(Invoice $invoice): void
    {
        $mailer = new SmtpMailer(env('MAIL_HOST'));   // hidden dependency, real email in tests
        $mailer->send($invoice->email, new InvoiceMail($invoice));
    }
}

After: how you implement the DI Container pattern in PHP

final class InvoiceSender
{
    public function __construct(  // ask, don't build
        private Mailer $mailer,
        private \Psr\Log\LoggerInterface $log,
    ) {}

    public function send(Invoice $invoice): void
    {
        $this->mailer->send($invoice->email, new InvoiceMail($invoice));
        $this->log->info('invoice.sent', ['invoice' => $invoice->id]);
    }
}

// AppServiceProvider: the ONE place that decides what Mailer means
$this->app->singleton(Mailer::class, fn () => new SmtpMailer(config('mail.host')));  // "only one", visibly

// Controller: Laravel builds InvoiceSender and fills its constructor
public function store(Invoice $invoice, InvoiceSender $sender) { $sender->send($invoice); }

// Test: no container needed, no real email
$mailer = new FakeMailer();
(new InvoiceSender($mailer, new \Psr\Log\NullLogger()))->send($invoice);
$this->assertCount(1, $mailer->sent);

Highlighted lines are the ones that make it this pattern.
